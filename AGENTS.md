# Codex Usage Strip

- This checkout is the public Windows project. Preserve the native child-window UI and read-only account API boundary.
- Publish only source, tests, docs and requested release artifacts. Never include account credentials, local configuration, runtime records, usernames, private paths or process IDs.
- Use unique owned run directories under OS temp for builds and tests; record ownership and dispose owned processes and files in finally. Keep one compact current verification record outside the public checkout.
- Do not modify or stop the user's live Codex window for tests. Use isolated offscreen fixtures or passive capture.
- A single agent owns each source file. Run change-relevant tests and an independent review before publication. Keep Chinese and English usage instructions consistent.
